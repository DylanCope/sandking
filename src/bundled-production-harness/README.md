# Sand-King Sandcastle Harness

This is Sand-King's reproducible production Harness seed. Its orchestration is the bundled known-good Sand-King `.sandcastle` implementation built on the exact `@ai-hero/sandcastle` package recorded in `package-lock.json`. `provenance.json`, `seed-manifest.json`, and `skills.lock.json` make the seed, upstream source, dependencies, Worker skill inventory, and execution-runtime inputs auditable from the Harness commit.

The conformance Harness is separate and remains the deterministic offline acceptance oracle.
